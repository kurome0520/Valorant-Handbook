# VALORANT Personal Hub V1

A GitHub Pages-ready personal VALORANT dashboard.

## V1 features
- Dashboard
- Daily aim training checklist
- Maps + one main agent per map
- Lineup database
- Personal notes
- Tracker.gg shortcut
- View mode / Admin edit mode
- Export / Import JSON backup
- Responsive layout

## Demo admin password
`valorant`

> This password is only a front-end demo and is not secure. Before public deployment, replace it with Supabase Auth + Row Level Security.

## Run locally
Open `index.html`, or use VS Code Live Server.

## Deploy
This folder can be pushed directly to GitHub and published with GitHub Pages.
